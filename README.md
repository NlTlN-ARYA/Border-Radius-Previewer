# Border-radius Previewer

A simple, interactive web application that lets users customize CSS border-radius values and preview the resulting shape in real time.

## Features

- Live preview of border-radius changes.
- Four adjustable corner values: top-left, top-right, bottom-right, and bottom-left.
- Advanced mode with all eight horizontal and vertical radius values.
- Generated CSS updates automatically.
- One-click CSS copying to the clipboard.
- Reset button to restore default values.
- Responsive interface for desktop and mobile screens.

## Demo

Run the project locally by opening `index.html` in your web browser.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Open `index.html` in your browser.
2. Adjust the sliders or enter values in pixels.
3. Watch the preview update automatically.
4. Open Advanced mode to customize all eight radius values.
5. Click **Copy CSS** to copy the generated CSS.
6. Click **Reset Values** to restore the defaults.

## Example

```css
border-radius: 25px 50px 25px 50px;
```

Advanced example:

```css
border-radius: 25px 50px 25px 50px / 25px 50px 25px 50px;
```
